# Task Board - Monolithic Architecture (Complete)

## Features
- ✅ View tasks
- ✅ Create task
- ✅ Move task (TODO → IN_PROGRESS → DONE)
- ✅ Delete task
- ✅ Filter by status

## Setup
```bash
1.ทำการ clone git ด้วยคำสั่ง git clone git@github.com:Peerapong67/engse207-labs.git
2.ทำการเข้าไปที่ folder week3-monolithic ด้วยคำสั่ง cd engse207-labs/week3-monolithic/
3.ทำการติดตั้ง npm ด้วยคำสั่ง npm install 
4.ทำการเริ่มต้นการทำงานด้วยคำสั่ง npm start
